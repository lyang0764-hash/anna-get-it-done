# Anna 通用网站 UI Brief

## 项目变量

- 网站名称：Anna姐 · 把事干成
- 项目 Slogan：把事干成
- 首页对话主提示：最想把什么事情做成？
- 一句话目的：把用户的一句话和资料转成可直接使用的深度成果与正式 PDF。
- 主要用户：Anna 管理员与获授权的独立子账号。
- 管理员角色：管理员可管理成员、服务与 Key；成员只能使用自己的工作台。
- 原始 Logo 文件路径/来源：现有 `BrandLogo` 品牌组件，保持已验收字标不变。
- 是否公开访问：域名公开，应用内容必须登录后访问。
- 是否使用外部 API：OpenAI Responses API，由管理员在系统设置配置。

## 页面地图

| 页面 | 页面模式 | 主要任务 | 主要动作 | 权限 |
| --- | --- | --- | --- | --- |
| 登录页 | 表单/任务 | 使用账号和密码进入独立工作台 | 登录 | 未登录 |
| 对话工作台 | 工作台 | 提交任务、恢复任务、继续深入 | 生成成果 | 已登录 |
| Library | 列表/资产 | 查找并打开当前账号成果 | 搜索、打开、下载 | 已登录且仅本人数据 |
| 系统设置 | 系统设置 | 管理账号、成员、服务与 Key | 新增/停用/删除成员、保存 Key | 管理员 |

## 工作台导航

- New chat 行为：主动清空当前草稿和任务上下文。
- Library 文件来源与打开行为：D1 中当前登录账号的完成报告，可搜索、打开和下载。
- Chats 历史来源与续聊行为：D1 中当前登录账号的生成任务，可恢复原问题和结果。
- 底部账号/系统入口：显示真实当前账号、角色、退出登录与系统设置。
- 移动端主任务：登录、提交任务、打开历史成果和退出。

## 单一输入窗

- 允许的输入方式：文字、粘贴、图片、文件、语音。
- 初始正文高度：34–48px。
- 最大正文高度：桌面 320px / 移动 280px。
- 草稿保存方式：按账号隔离的浏览器草稿；正式任务和报告保存到 D1。
- 提交后保留原文：是。
- 唯一允许清空的动作：New chat。

## 外部服务与 Key

| 服务 | 用途 | 谁可配置 | 测试方式 | 未连接时降级 |
| --- | --- | --- | --- | --- |
| OpenAI | 深度研究与结构化报告 | 仅管理员 | 服务端最小请求 | 明确提示管理员配置 |

## 固定骨架验收

- [ ] 未登录无法进入工作台和 API
- [ ] 管理员可新增、停用、启用、删除子账号
- [ ] 普通成员看不到成员管理与服务 Key
- [ ] Chats 与 Library 按登录账号隔离
- [ ] 密码只保存 PBKDF2 哈希，会话使用 HttpOnly Cookie
- [ ] 桌面、平板与移动端均可完成登录和退出
